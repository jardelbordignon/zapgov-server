Usando postgres para persistir os dados

Exemplo de instalção do postgres no docker
docker volume create postgres-volume
docker run --name postgres -p 5432:5432 -v postgres-volume:/var/lib/postgresql/data -e POSTGRES_PASSWORD=docker -d postgres

docker start postgres

nesse exemplo de instalação ficou username "postgres" e password "docker" então no .env do projeto
precisa configurar a var DATABASE_URL exatamente como está no .env.example
